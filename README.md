# Academy Tech Kids 🚀

> **Construindo o futuro através da educação, da tecnologia e da curiosidade.**

**Academy Tech Kids** é um projeto educacional open source que une mentoria, tecnologia e desenvolvimento pessoal para crianças e adolescentes.

O objetivo é criar uma metodologia leve, prática e gamificada que estimule o pensamento crítico, a comunicação, a organização e a autonomia, preparando os alunos para um mundo cada vez mais conectado à tecnologia.

---

# 📖 Sobre o Projeto

A proposta do Academy Tech Kids é mostrar que aprender pode ser divertido quando existe propósito.

Mais do que ensinar conteúdos escolares, o projeto busca desenvolver habilidades que acompanharão os alunos por toda a vida, como:

* Comunicação clara;
* Pensamento lógico;
* Organização;
* Educação financeira;
* Curiosidade tecnológica;
* Disciplina;
* Resolução de problemas;
* Trabalho com metas e objetivos.

Todo o conteúdo é organizado em um repositório Git, permitindo evolução contínua da metodologia, versionamento do material e colaboração da comunidade.

---

# 🎯 Objetivos

Ao final do programa, espera-se que o aluno seja capaz de:

* Ler e interpretar textos com maior confiança.
* Produzir pequenas redações e apresentações orais.
* Resolver problemas matemáticos do cotidiano.
* Compreender conceitos básicos de educação financeira.
* Utilizar inglês e espanhol em situações simples relacionadas à tecnologia.
* Entender como computadores, internet e redes funcionam.
* Desenvolver pensamento computacional e lógica.
* Criar os primeiros algoritmos.
* Utilizar Inteligência Artificial de forma responsável.
* Organizar seus estudos e acompanhar sua própria evolução.

# 🏆 Sistema de Recompensas

O programa utiliza uma abordagem baseada em disciplina, constância e evolução.

## Recompensa Mensal

* Mesada de **R$ 120,00**, condicionada ao comprometimento, participação e cumprimento das atividades propostas.

## Conquista Final

Ao concluir o programa demonstrando dedicação e evolução contínua, o aluno celebrará essa conquista com um **PC Gamer novo**.

> **O foco não é a perfeição. O foco é construir o hábito de aprender, evoluir e nunca desistir diante dos desafios.**

# 🚀 Como Utilizar

1. Leia a [metodologia](docs/methodology.md) e o [guia do mentor](docs/mentor-guide.md).
2. Organize o caderno conforme as [orientações](docs/notebook-organization.md).
3. Escolha a semana correspondente em `weekly/week-XX/README.md`.
4. Aplique as atividades e ofereça as adaptações necessárias.
5. Use o [roteiro do encontro](templates/weekly-meeting.md).
6. Registre a evolução sem dados pessoais no repositório público.
7. Planeje os desafios da próxima semana.

## Experiência web

Abra `index.html` em um navegador moderno para usar a microaula e o teste da Semana 1. A página funciona sem cadastro, não envia respostas para um servidor e permite realizar o teste sem limite de tempo.

Para executar as verificações locais, use Node.js 18 ou superior:

```bash
npm test
npm run validate
```

Consulte a [política de privacidade do MVP](docs/privacy.md), a [avaliação](docs/evaluation.md) e o [padrão de conteúdo](docs/content-standard.md) antes de criar novas atividades digitais.
