# Como contribuir

1. Crie uma branch a partir da `main`.
2. Utilize nomes como `feature/week-05` ou `docs/improve-methodology`.
3. Faça alterações pequenas e claras.
4. Revise ortografia e formatação Markdown.
5. Abra um Pull Request explicando objetivo, alterações e testes realizados.

## Padrão de commits

- `docs: adiciona metodologia`
- `feat: cria atividades da semana 05`
- `fix: corrige cálculo da atividade financeira`
- `refactor: reorganiza currículo de tecnologia`
