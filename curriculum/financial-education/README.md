# Educação financeira

## Objetivos

- Compreender receita, gasto, poupança e planejamento.
- Diferenciar necessidade e vontade.
- Registrar o uso da mesada de R$ 120,00.
- Criar objetivos de curto e médio prazo.

## Regra inicial sugerida

O aluno deve propor sua própria divisão. Como referência didática:

- R$ 60,00 para objetivo ou poupança;
- R$ 40,00 para uso pessoal;
- R$ 20,00 para reserva, presente ou doação.

A divisão não é obrigatória. O importante é justificar as escolhas.
