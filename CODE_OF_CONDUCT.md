# Código de conduta

Este projeto promove respeito, acolhimento e aprendizagem segura.

Não são aceitos:

- humilhação por erros;
- discriminação;
- exposição de menores;
- linguagem ofensiva;
- competição destrutiva;
- publicação de dados pessoais.

Toda contribuição deve preservar a segurança e o desenvolvimento dos alunos.
