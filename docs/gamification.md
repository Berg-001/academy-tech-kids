# Gamificação responsável

## Objetivo

A gamificação ajuda a tornar o progresso visível. Ela não deve criar medo, humilhação, comparação pública ou pressão financeira.

## Conquistas sugeridas

- **Curioso:** fez uma boa pergunta.
- **Persistente:** revisou uma tentativa.
- **Comunicador:** explicou o raciocínio com clareza.
- **Colaborador:** ajudou sem entregar a resposta.
- **Guardião digital:** tomou uma decisão segura na internet.

## Regras

- Não usar ranking público.
- Não retirar conquistas já obtidas.
- Reconhecer processo, consistência e recuperação.
- Oferecer caminhos equivalentes para diferentes habilidades.
- Separar recompensas financeiras de uma nota isolada ou do tempo de resposta.

O mentor deve revisar mensalmente se as recompensas continuam motivadoras e justas para cada aluno.
