# Recursos educacionais

Registrar aqui livros, vídeos, sites, jogos educativos e ferramentas aprovadas pelo mentor.

Antes de adicionar um recurso, verificar:

- linguagem adequada à idade;
- ausência de conteúdo impróprio;
- confiabilidade da fonte;
- publicidade excessiva;
- necessidade de cadastro;
- coleta de dados pessoais.
